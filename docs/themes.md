# Themes

```sh
theme selenized-light         # from anywhere; or: task theme -- <name>
task theme-preview            # see all four first
```

| Name | Palette |
|---|---|
| `selenized-dark` | [Selenized](https://github.com/jan-warchol/selenized) dark |
| `selenized-light` | Selenized light |
| `solarized-osaka-dark` | [Solarized Osaka](https://github.com/craftzdog/solarized-osaka.nvim) night (default) |
| `solarized-osaka-light` | Solarized Osaka day |

Result: Ghostty reloads at once; VSCodium, Vim, `ls` colours and git's delta
pager use the theme from their next start. `task link` keeps the theme in
use.
